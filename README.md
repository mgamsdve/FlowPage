## Project Overview

### What is FlowPage?

FlowPage is an **agency for web presence** focused on clarity, readability, and credibility. It helps independent professionals and small businesses build a simple, understandable, and trustworthy online presence that accurately reflects their activity and identity.

**FlowPage is not:**
- A marketing agency with aggressive sales tactics
- A vendor of guaranteed conversion promises
- A "full design" studio at the expense of usability
- A factory for standardized templates
- An automated platform

### Core Philosophy

- **Clarity over originality** - Clear communication matters more than fancy design
- **Less information = Better comprehension** - Reduce cognitive load
- **Structure matters** - Information hierarchy and readability are paramount
- **Mobile-first** - Responsive and accessible by default
- **Client autonomy** - Clients should feel empowered after working with FlowPage

### Brand Positioning

- Premium but accessible
- Serious, calm, and reassuring
- Human-focused, not technical
- No artificial urgency
- No jargon, no exaggerated promises

## Installation & Setup

### Prerequisites

- **Node.js** (recommended: v18 or higher)
- **pnpm** (v10.30.3) - Install globally with: `npm install -g pnpm@10.30.3`

### Step 1: Clone the Repository

```bash
git clone <repository-url>
cd FlowPage/Web
```

### Step 2: Install Dependencies

```bash
pnpm install
```

This will:
- Install Vite, Tailwind CSS, and all dev dependencies
- Generate `node_modules/` directory
- Create/update `pnpm-lock.yaml`

### Step 3: Verify Installation

Check that dependencies are installed correctly:

```bash
pnpm list
```

Expected output should show:
- `tailwindcss@4.2.1`
- `@tailwindcss/vite@4.2.1`
- `vite@7.3.1`

## Development

### Start Development Server

```bash
pnpm run dev
```

This will:
- Start Vite dev server (typically at `http://localhost:5173`)
- Enable hot module reloading (HMR)
- Watch for changes in HTML, CSS, and JavaScript
- Compile Tailwind classes on-the-fly

**Features:**
- Automatic browser refresh on file changes
- Fast rebuild times
- In-browser error messages

### Development Workflow

1. **Edit HTML** (`index.html`) - Add new sections or content
2. **Update Styles** (`assets/css/styles.css` or use Tailwind classes in HTML)
3. **Add JavaScript** (`assets/js/main.js`) - Enhance interactivity
4. **Check in browser** - Changes appear automatically

### JavaScript Functionality

The main JavaScript file (`assets/js/main.js`) includes:

- **FAQ Accordion** - Collapsible FAQ items with smooth animations
- **Reveal Animations** - Scroll-triggered element reveals using IntersectionObserver
- **Impact Section Animation** - Scroll-based animations for project examples
- **Textarea Auto-resize** - Dynamic height adjustment for contact form textarea
- **Lucide Icons** - Icon initialization via CDN

No build step needed for JavaScript - changes are hot-reloaded during development.

## Building & Deployment

### Build for Production

```bash
pnpm run build
```

This will:
- Minify HTML, CSS, and JavaScript
- Optimize images (if configured)
- Generate production-ready files in the `dist/` directory
- Optimize Tailwind CSS (removes unused styles)

**Output:**
```
dist/
├── index.html
└── assets/
    ├── css/
    └── js/
```

### Preview Production Build

To preview the built version locally:

```bash
pnpm run preview
```

This serves the `dist/` folder locally, simulating production environment.

### Deployment Options

The built files in `dist/` can be deployed to:

- **Vercel** - Recommended for Vite projects
  ```bash
  npm install -g vercel
  vercel
  ```

- **Netlify** - Drag-and-drop or CLI
  - Connect GitHub repository
  - Set build command: `pnpm run build`
  - Set publish directory: `dist`

- **Traditional Hosting** - Upload contents of `dist/` via FTP/SFTP

- **Docker** - Create a Dockerfile that builds and serves with Nginx

### Environment-Specific Configs

Current project uses:
- **Email contact**: `contact@flowpage.tech` (hardcoded in HTML footer)
- **No environment variables** currently used
- Static site - no backend required

## Troubleshooting

### Issue: `pnpm: command not found`
**Solution**: Install pnpm globally
```bash
npm install -g pnpm@10.30.3
```

### Issue: Dev server won't start
**Solution**: Check for port conflicts or clear Vite cache
```bash
rm -rf .vite
pnpm run dev
```

### Issue: Tailwind classes not applying
**Solution**: Ensure content paths in `tailwind.config.mjs` are correct
```javascript
content: [
  "./index.html",
  "./assets/**/*.{js,html}",
]
```

### Issue: Styles not loading in production build
**Solution**: Run full rebuild
```bash
rm -rf dist node_modules
pnpm install
pnpm run build
```

## Performance Optimization Tips

1. **Image Optimization** - Compress and use modern formats (WebP)
2. **Lazy Loading** - Use native `loading="lazy"` for below-the-fold images
3. **Critical CSS** - Already optimized by Tailwind + Vite
4. **Font Loading** - Currently using `display=swap` for optimal performance
5. **Bundle Size** - Monitor with `pnpm run build` output
6. **Caching** - Use appropriate cache headers in deployment
